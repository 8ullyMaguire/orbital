The adult host is `nsfwlinks.polarisocial.xyz` and not `nsfw.links.polarisocial.xyz`
for one concrete reason: Cloudflare's Universal SSL covers `*.polarisocial.xyz`,
one label deep. A two-level hostname fails the TLS handshake with no certificate
and no useful error, so the single-label name is the one that can actually serve.

## What is deliberately not built

- **Quorum moderation.** A vote needs a population; with one operator it is a
  form that never closes. Vertical-scoped flag queues exist and are resolved by
  the owner (dashboard → Admin).
- **Email.** This host has no SMTP transport. Handle + password, plus an optional
  Bluesky handle claim proven by a token in that account's profile description.
- **A taste co-occurrence matrix as a table.** Similarity is computed from the tag
  vectors in SQL. A materialised matrix is a cache with no invalidation story.
- **Crawler-facing client rendering.** Every public page is HTML from the server.

## First week

The boards are honest about being empty: a vertical with one member says so, and
`Trending` refuses to pad itself with zero rows. The first real numbers come from
the footer links and from the profile link being shared. Watch
`/app/` → Overview → "Where they came from": `embed` and `vertical` entries mean
the discovery loop is working, `direct` means traffic is arriving from somewhere
that was not tagged.
