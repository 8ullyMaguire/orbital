## What is deliberately not built

- **Quorum moderation.** A vote needs a population; with one operator it is a
  form that never closes. Vertical-scoped flag queues exist and are resolved by
  the owner (dashboard → Admin).
- **Email.** This host has no SMTP transport. Handle + password, plus an optional
  Bluesky handle claim proven by a token in that account's profile description.
- **A taste co-occurrence matrix as a table.** Similarity is computed from the tag
  vectors in SQL. A materialised matrix is a cache with no invalidation story.
- **Crawler-facing client rendering.** Every public page is HTML from the server.

## First week

The boards are honest about being empty: a vertical with one member says so, and
`Trending` refuses to pad itself with zero rows. The first real numbers come from
the footer links and from the profile link being shared. Watch
`/app/` → Overview → "Where they came from": `embed` and `vertical` entries mean
the discovery loop is working, `direct` means traffic is arriving from somewhere
that was not tagged.


## Personalisation

The tuner is live on `/` and every vertical page: a visitor drags tags and the lists reorder for
them, with no account. Weights live in `preference_weights` (SPEC-V3), explicit ones never decay, and
passive ones from browsing halve every 30 days. Members can see, in their dashboard, what their
visitors care about.

## What else is live (2026-10-29, late)

Beyond the tuner:

- **`/lens`** — your weights as an editable table, "this browser" or "your account", with an off
  switch (`/prefs/off`) for anyone who would rather see the honest order.
- **`/status`** — every hostname nginx serves, with code and latency, cached a minute. The list is
  generated by the deploy from `server_name`s, so it cannot drift from the network it describes.
- **Social cards** — `/og/{handle}.png`, generated from the same data as the profile; the first share
  of a member is not a grey rectangle.
- **Governance** — members propose verticals, three TL3 votes decide, a merge moves people with their
  tags. `GET /api/verticals/proposals` says what is on the table.
- **Endorsements** — TL2+ can second a tag; three endorsements are worth up to +0.2 of relevance, as
  their own term, because relevance saturates.
- **Tokens** — `POST /api/me/tokens` for scripts; the public read API is unchanged and still needs no
  credential at all.
- **Spanish** — `/lang/es`, or `Accept-Language` on a first visit. The chrome is translated; the page
  bodies are the next pass (`ROADMAP.md`).
- **`orbital doctor`** — the runbook as code; run it after every deploy and when something feels
  wrong. Seven timers keep the rest honest (backup, restore test, prune, snapshots, link checks,
  metadata and cards, uptime).

The honest read of the first week is unchanged: four members, no audience yet, and a measured
pageview count of zero on this host (`docs/monetization.md`). The product is ready to be given to
people; it is not ready to be monetised, and pretending otherwise would be the first untrue thing on
the site.
